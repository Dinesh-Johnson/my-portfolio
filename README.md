# Dinesh Johnson - Developer Portfolio

A highly modern, brutalist-inspired developer portfolio built with React and Vite. The layout utilizes a responsive "Bento Box" CSS grid designed to showcase my core stack, projects, and personality as a Java Full Stack Developer.

## 🚀 Live Demo
[View Live Portfolio](https://Dinesh-Johnson.github.io/my-portfolio)

## ✨ Key Features
- **Brutalist Monochrome Aesthetic:** Deep charcoal background with stark beige cards and sharp borders for a premium, high-contrast look.
- **Bento Grid Layout:** Fully responsive, interlocking grid design that cleanly scales from desktop down to mobile devices.
- **Mouse Tracking Glow:** Cards feature a subtle, radial gradient glow effect that tracks the user's mouse cursor across the grid.
- **Interactive Personality Section:** Features auto-rotating fun facts and quotes spanning software engineering, Real Madrid, and One Piece.
- **Dynamic CSS Variables:** Highly maintainable styling using strict CSS variables for seamless theme scaling.

## 🛠 Tech Stack
- **Frontend Framework:** React 19 + Vite
- **Styling:** Custom CSS (Brutalist theme), CSS Grid
- **Icons:** Bootstrap Icons
- **Animations:** AOS (Animate On Scroll)

## 📦 Local Development
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the local development server
4. Run `npm run build` to compile the production bundle

## 🌐 Deployment
This portfolio is configured to deploy automatically to GitHub pages. To push a new production build, simply run:
```bash
npm run deploy
```
